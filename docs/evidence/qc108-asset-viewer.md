# QC-108 前端：素材檢視（方案 B 圖庫檢視）

日期：2026-11-26 · 會話：qc-frontend · 分支 `qc108-asset-viewer`（從 origin/main 7fc7ffb 開）

規格：
- 原型 PT-20261126-001，使用者核准方案 B，七個問題全部照推薦。
- `docs/decisions.md`「2026-11-26 · 素材檢視改為內容優先原型核准（QC-105）」六點。
- 原型截圖 `docs/evidence/qc105-prototype/`（`b-*.png`、`keys.png`）。

併入：視頻素材卡沒有縮圖（QC-104 報告提到的範圍外問題）。

## 做了什麼

- **單擊進檢視**：
  - 單擊素材卡，在主區內顯示（`AssetViewer.tsx`），左側導覽保留。
  - 檢視蓋在網格上；網格不卸載，回去時捲動位置不變，焦點回到原卡片。
  - 原本的右側常駐檢視器（`AssetInspector`）和多選側欄（`MultiInspector`）都拿掉了。
- **檢視版面**：
  - 工具列：‹ 素材庫、序號、資訊、在 Finder 顯示、移到回收站（外部素材是「移出素材庫…」）、更多。
  - 內容佔滿舞台。
  - 下方一行淡化資訊：名稱、尺寸或字數、時長、大小、用在幾個作品或「未引用」、標籤。滑過時恢復全對比。
  - 底部 84px 縮圖條：可以點選，目前那張會自動捲進可見範圍。
- **資訊卡**：
  - 按 I 或「資訊」才浮出，每次進檢視都是收起的。
  - 浮在內容上方，內容大小不變。
  - 欄位：名稱、標籤、替代文字（只有圖片有）、備註、用在（點了開作品）、檔案資訊（摺疊）。
  - 自動儲存，衝突處理沿用 QC-037 的 `AssetEditor`。
- **按鍵**（對照 `keys.png`）：

  | 按鍵 | 動作 |
  | --- | --- |
  | ← → | 切換素材，在頭尾停住 |
  | ↑ ↓ | 不綁定 |
  | I | 開關資訊卡 |
  | F | 視頻全屏（沿用 QC-104） |
  | 空白鍵 | 視頻、音訊播放暫停；圖片、Markdown 開 QC-077 全視窗預覽 |
  | Esc | 先關資訊卡，再回網格；全屏中先退全屏 |
  | ⌘⌫ | 刪除，之後跳到下一個素材，⌘Z 可以復原 |

  網格中的空白鍵仍然開全視窗預覽，QC-077 不變。
- **四種內容**：
  - 圖片：等比放大到舞台大小，不裁切。縮放沿用 QC-077：⌘＋、⌘－、⌘0、捏合、雙擊切換「適合／100%」、拖曳平移。
  - 視頻、音訊：原生完整控制。
  - Markdown：排版閱讀，版心 680px。「更多」選單可以切換「顯示原始文字／顯示排版」，也可以「複製文字」。全視窗預覽也顯示排版後的文字。
  - 其他檔案：顯示圖示和「無法在這裡預覽」。
- **多選**：
  - ⌘ 點選只做多選，不開檢視。
  - 頁首變成「已選 N」動作列：加標籤、在 Finder 顯示、移到回收站、取消選取（Esc）。
  - 動作列在捲動時固定在上方。
- **回收站**：點名稱進同一個檢視，工具換成「恢復」「永久刪除」，結束後跳到下一個。外部掛載素材和回收站原本的對話框不變。
- **動效**：
  - 進檢視時，內容從卡片的位置放大到定位，用 QC-077 的 `expandFrom`，moderate/out。只在完整動效模式下播放。
  - 資訊卡用 `panel` preset 從右側淡入，退出由 `Presence` 處理。
  - 回網格不做反向動畫，見下方偏差 3。
- **視頻縮圖**（`video-thumbs.ts`）：
  - 服務端只為圖片產生縮圖（`thumbnailFile` 只接受 image），所以視頻卡一直只顯示圖示。
  - 現在由 App 在卡片進入畫面時，用隱藏播放器擷取 1 秒處的一格：一次處理一支，每支只擷取一次，存在本次執行的記憶體裡，最多 400 張。
  - 網格、縮圖條、回收站共用同一份。Chromium 解不開的格式保留圖示。
- **主行程**：
  - 新增 IPC `creatorhub:asset-text`（`readAssetText`）。
  - 只接受素材 id，帶權杖向服務要 `stream` 的前 1 MB（Range）。超過時只回傳開頭，並標註 `truncated`。
  - `copyText` 的長度上限從 1 萬字元放寬到 1 MB，這樣「複製文字」能複製整份 Markdown。
- **i18n**：
  - 新增鍵三語齊全。
  - 刪掉不再使用的六個鍵：`inspector`、`closeInspector`、`pickedAssets`、`multiHintFields`、`openLarge`、`refsFailed`。

## 與原型的比對與刻意偏差

在相同主題、相同的合成內容下，逐張對照 `b-grid`、`b-image`、`b-info`、`b-video`、`b-markdown`、`b-audio`、`b-multi`：

1. **視頻控制列用 Chromium 原生 controls。** 原生 controls 已有播放、進度、音量、全屏（QC-104），速度與子母畫面在 ⋮ 選單裡。原型畫出的 **±15 秒按鈕**和**進度條懸停縮圖**沒有做。要做的話得自己畫整條控制列，建議另開任務。
2. **音訊沒有大波形。** 現在是一張卡片：圖示、名稱、原生播放器。
   - 波形需要解碼整個音檔，或者由服務端用 ffmpeg 算出峰值。
   - renderer 的 CSP `connect-src` 不允許讀 `qc-asset:`，所以在前端解碼要另外開 IPC，大檔也慢。
   - 建議由後端提供 peaks 端點後再接上。
3. **回網格沒有反向的縮回動畫**（原型 motion 說「leaving reverses」）。卡片在網格底下，量不到穩定的位置，所以現在是直接切回網格。
4. 頁首多選標題沿用既有字串「已選 N」，原型寫的是「已選 N 個」。
5. 資訊卡標題列除了「自動儲存」，還保留儲存狀態籤（已儲存、儲存中、衝突）。沿用 QC-037 的回饋，衝突時需要它。
6. 素材庫頁首（搜尋、範圍、上傳、類型篩選）維持現狀。原型 `b-grid` 把類型篩選併進頁首，這次沒有動網格頁首。

  - ← → 在頭尾停住；點縮圖條切換。
  - 回網格時捲動位置不變，焦點回到原卡片。
  - 音訊、視頻用空白鍵播放暫停。
  - Markdown：標題、粗體、引用、清單、字數；「更多」切換原始文字和排版；空白鍵開全視窗預覽並顯示排版。
  - 圖片空白鍵開全視窗預覽，Esc 回到檢視。
  - 深色主題、多選。
  - 檢視中刪除後跳到下一個；回收站檢視。
- 改寫的既有 e2e：

    - 欄位改在資訊卡裡編輯。
    - 刪除後檢視跳到下一個。
    - 多選沒有側欄，有「在 Finder 顯示」。
    - 回收站檢視可以恢復。
  - `asset-lightbox.spec.ts`：

  - `video-fullscreen.spec.ts`：
    - 檢視中的視頻可以全屏，F 鍵也行。
    - Esc 退出全屏後仍留在檢視。
  - `editor-insert.spec.ts`：刪除按鈕改在檢視的工具列。
- 新單元測試：
  - `asset-viewer.test.ts`：按鍵對應、刪除後的下一個、字數、擷取時間。
  - `video-thumbs.test.ts`：一次一支、只擷取一次、失敗不重試、離開畫面取消、上限。
  - `asset-text.test.ts`：只接受 id、權杖與 Range、截斷時不切壞字元、失敗回 null。
- 修正一個在實作中發現的競態：
  - 刪除或恢復的請求回來時，`afterRemoval` 用的是舊的 `view`。如果使用者已經回到網格，檢視會被重新打開，而且蓋住網格。
  - 現在改用 ref 讀最新狀態；e2e `assets.spec.ts` 的回收站步驟能重現這個問題。
