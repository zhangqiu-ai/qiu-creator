## 做了什麼

- **項目頁分段**（`LibraryPage.tsx`、`ProjectGroups.tsx`、`project-groups.ts`）：
  - 未分組排在最上面，有作品才出現。段首附一行歸組提示，沒有「⋯」，所以不能改名、刪除或排序。
  - 段首包含折疊箭頭、名稱、數量、系列膠囊（「系列 · N 集」）、Agent 建立標記（QC-091 的 accentSoft 加機器人圖示），以及「⋯」。網格模式下段首 sticky。
  - 分組折疊後只留一行，最多 4 張小縮圖，加上前兩個標題。折疊狀態依項目記住（`localStorage`）。
  - 空的分組顯示虛線放置區：「把作品拖到這裡，或右鍵「移到分組」」。
  - 頁首有「＋ 新分組」，副標加「N 個分組」。
  - 項目還沒有分組時，仍是原本的平鋪網格；入口是「＋ 新分組」和右鍵「移到分組 ▸ 新分組…」。
- **系列**：
  - 卡片左上角標「第 N 集」，列表多一欄「集」。
  - 拖曳時，插入線決定落在第幾集。右鍵也有「往前一集／往後一集」，鍵盤一樣能改集數。
  - 集數由服務重新編號，不會留空號。
- **拖曳歸組**（和側欄共用的 `ProjectsDnd`）：
  - 拖曳中：
    - 原位留淡化的虛影；目標分組顯示虛線框，段首右側寫「放開以移到「X」」。
    - 跟手的標籤寫「移到 X · 第 N 集」，一般分組只寫「移到 X」。
    - 拖到折疊的分組上停 0.6 秒會展開。
  - 可以多選一起拖，作品依畫面上的順序放入；按 Esc 取消。
  - 拖段首可以排序分組。
  - 減少動態效果時沒有落位動畫，只留插入線和目標框（沿用既有的拖放規則）。
- **選單**：
  - 右鍵或多選後，批量列的「移到分組 ▸」列出未分組和各分組，系列會寫「放到第 N 集」；最後一項「新分組…」可以直接建立分組並放入。
  - 分組的「⋯」：重新命名（就地改名）、當作系列（勾選項）、上移／下移、折疊其他分組、刪除分組…（附註「作品回到未分組」，先跳確認對話框）。
- **全部作品**：不分段，只在卡片的項目標籤後面加淡色的「› 分組 #集數」。寬度不夠時，先縮短分組名稱。
- **即時與錯誤**：
  - 分組的修改會先顯示在畫面上，再以服務的回應為準。
  - 收到 `project.groups_changed` 就重讀分組，所以 Agent 或其他裝置的修改會即時出現。
  - 409 和其他錯誤：重讀分組，並用既有的錯誤文字跳 toast。
- **提示**（QC-115）：歸組、改名、排序、建立、刪除的結果都在畫面上，所以不跳 toast；只有錯誤會提示。
- **三語文案**：新的 `groups` 區（繁中、簡中、英文）。
- 沒有新增或修改 `/api/v1` 路由，所以 MCP 不需要同步。
- 架構說明：`docs/architecture.md`「項目分組與系列：Mac 介面（QC-114）」。

### 和原型的差異

- 原型的段首選單有「在新視窗打開」。這次派工的範圍沒有列這一項，App 也沒有分組視窗，所以沒做。
- 原型的「＋ 新分組…」前面有加號圖示。App 的右鍵選單（`ContextMenu`）不支援圖示，所以只顯示文字「新分組…」。
- 卡片沿用 App 現有的卡片（狀態、類型、時間），沒有照原型的合成卡片樣式。列表沿用 App 現有的欄位，多加「集」欄和把手。
- 原型頁首有「4 個分組」。截圖的測試資料只有 3 個分組，所以顯示「3 個分組」。
- 列表的段首不是 sticky：表格外層會橫向捲動，sticky 在裡面不會生效。
- 跟手標籤：保留現有的拖曳浮層（標題或「N 個作品」），下面加一顆藍色膠囊。原型是一張卡片的縮小副本加膠囊。

## 自動測試

- `apps/mac/test/project-groups.test.ts`（20 個）：
  - 分段：未分組的位置、還沒載入的作品怎麼計數、篩選時的數量。
  - 集數、本地套用的歸組與排序（規則與服務相同）、插入線的落點與換算成 `position`、什麼放置算沒有變更。
  - 折疊記憶：分開記每個項目；存儲壞掉時不出錯。
  - 選單：「移到分組」的勾選、「放到第 N 集」、新分組；「⋯」上移下移的邊界；往前／往後一集。
  - 拖曳資料：側欄的項目放置會忽略分組拖曳。
  - `ProjectGroupsStore` 接真服務：
    - 先在畫面上套用、重排集數、排序、刪除。
    - 別處改過分組時回 409：提示原因並重讀；同名分組提示 `group_name_taken`。
    - 只對自己項目的 `project.groups_changed` 重讀；切換項目時，丟掉舊項目的回應。
- `e2e/specs/project-groups.spec.ts`（1 個，十六個步驟）：
  - 分段、提示、系列集數、Agent 標記、sticky。
  - 拖進系列：插入線、虛線框、標籤；放下後重排集數，並核對服務端資料。
  - Esc 取消後什麼都沒變。
  - 多選一起拖到一般分組。
  - 右鍵「放到第 6 集」；未分組空了就消失。
  - 「新分組…」建立系列並放入。
  - 往前一集。
  - 「⋯」重新命名、上移（到頂後「上移」停用）、當作系列。
  - 拖段首排序分組。
  - 折疊其他分組，重新開啟後仍記得。
  - 拖到折疊的分組上停 0.6 秒會展開，放下後作品在裡面。
  - Agent 從外部建分組，畫面即時出現。
  - 刪除分組後作品回到未分組；沒有 toast。
  - 列表的「集」欄、深色、全部作品的「› 分組 #集數」。

## NOT_VERIFIED

- 真實的觸控板拖曳與自動捲動手感：e2e 用滑鼠事件在背景視窗模擬；自動捲動只在除錯時另外量過一次（浮層跟手，目標框正確）。
- 簡中和英文版面寬度：文案三語齊全（目錄測試通過），截圖只有繁中。
- 分組很多時（接近上限 100 組）的捲動與拖曳效能。
- 列表模式的插入線（系列裡的列上下緣）：沒有截圖，e2e 只在網格模式拖曳。
- 拖段首排序時的插入線樣式：有自動測試，沒有截圖。
