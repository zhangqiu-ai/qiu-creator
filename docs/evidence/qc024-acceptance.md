## 設計決定與原型缺口

原型缺的狀態已在動工時回報總監，以下是目前的做法：

- **未設定金鑰或未確認告知**：面板頂端顯示一行提示加「前往設定」，生成按鈕停用。完整的設定在 QC-025。
- **供應商**：依 Claude → Gemini → GPT 取第一個可用的。標籤顯示「Claude · 雲端」，目前不能切換。
- **語氣**：選「語氣」時，補充指令框的內容就當作語氣，空白時不能送出。取消所有預設按鈕、只填指令時，送出「自訂」改寫。
- **標題分頁的生成中、失敗與無候選**：沿用改寫分頁的同一組元件。
- **寫入沒有版本的平台**：先從原稿建立版本，再寫入標題。
- **復原之後**：回到「無候選」，不再顯示原來的候選，因為它的基準版本已過時。
- **採用時 409**：組好的全文成為這個視窗的草稿，打開既有的衝突對話框。

## 刻意偏差

- 原型會在正文中把要改寫的段落標成底色。實作沒有：MDXEditor 和原始碼模式的 textarea 都不適合加這種標示。改用面板上的「選取：第 N 段 · 字數」，候選的 diff 也會列出原句。
- 復原後回到「無候選」；原型則是回到候選狀態。原因見上方「設計決定與原型缺口」。
- 原型的字數上限是示意值；實作以 contracts 為準：抖音 30、視頻號 16。
- 採用遇到 409 時，透過衝突對話框合併後產生的新版本，來源是 `edit`，不是 `ai_accepted`。
- 從面板「前往設定」後，再回到作品要從作品庫重新打開。
