## QC-075：輸出語言、模型、Prompt 快選、Prompt 頁

- **共用狀態** `ai-library.ts`：
  - 輸出語言與各任務上次用的模型，存在 Mac 服務端（`/ai/preferences`），三端共用。
  - 可切換的模型清單（`/ai/models?kind=chat`）。
  - Prompt 清單。
  - 工具列、右側面板、Prompt 頁讀寫同一份資料，一處改了，其他地方立即同步。
- **工具列**：潤色、擴寫、縮寫、語氣｜配圖｜Prompt｜輸出語言、模型。「更多」改名「Prompt」。
  - ⌘K 打開 Prompt 快選。在 capture 階段攔截，搶在編輯器的連結快捷鍵之前。
  - 語言選單：跟隨原文會寫出偵測結果（`detectLanguage`，與服務端相同）。
  - 模型選單：可搜尋、依就緒的供應商分組、標「上次用」；讀不到模型清單的供應商會標示出來；底部是「AI 服務 ›」。
  - 選了就全域保存，並用 toast 告知。
- **Prompt 快選**：一個欄位同時搜尋指令與接受直接輸入的指令。
  - 順序：最近使用（最多 3 條）→ 選取文字可用的 → 其他場景的（淡化停用）。
  - 命中以黃色 `mark.hit` 標出，拼音也會標到對應的字。
  - 輸入的文字不是某條指令的名稱時：第一項是「以「…」送出」，第二項是「存成 prompt…」，原地填名稱與分組。
  - 選取在視窗上方、放不下快選時，工具列改到選取下方，整個快選都在視窗內。
- **候選標示**：
  - 生成中的膠囊寫「動作 · 語言 · 模型…」。
  - 原位候選列與面板的候選，標出實際語言（跟隨原文時加註）與模型。
  - prompt 指定了模型或語言時，加標「prompt 指定」。
- **右側面板**只有「改寫」「圖片」。「改寫」頂部是語言與模型兩個選擇；下方是 Prompt 膠囊（內建四個方式加上選取文字用的自訂指令）與「管理」。原本的供應商下拉選單由模型選單取代。
- **Prompt 頁**（側欄「工具」→ Prompt）：
  - 內建指令唯讀，可「複製成自訂」。
  - 自訂指令可以原地改名，內容支援變數 `{選取}{標題}{全文}{平台}{語言}`（藍底標記，點按插入），也可設定用在、預設模型、輸出語言、分組，並顯示使用次數。
  - AI 依描述生成或改寫指令：結果以候選加 diff 呈現，按保留才寫入；改寫帶 `base_revision`，409 不靜默覆蓋。
  - 排序：拖曳，或 ⌥↑／⌥↓。
  - 匯出、匯入 JSON；同名的另存副本。
  - 刪除前確認；沒有自訂指令時有空狀態。

## QC-076：平台預覽併入作品編輯頁

- 側欄的「平台預覽」頁和路由都已移除（`PreviewPage.tsx` 刪除）。
- 編輯頁頂部「預覽」（⌘⇧P）打開右側分欄，寬 720，和 AI 面板、歷史、素材抽屜互斥。文章、貼圖、視頻共用 `PreviewPanel.tsx`。
- **平台切換**：小紅書、公眾號、抖音、視頻號，←→ 切換；尚未建立、超出上限、有衝突各有狀態點。
- **「版本」欄**：
  - 版本狀態，以及「重新從原稿產生」（確認框，舊版本留在歷史）。
  - 標題：n／上限，超出只警告，不阻擋儲存。
  - 正文、封面與圖片順序、標籤。
  - 尚未建立的平台：「從原稿建立」，不用 AI。
- **AI 標題**：只生成目前平台的候選，字數上限依平台。
  - 候選列在標題下方，標出語言與模型。
  - 點一個即套用並可復原（核准的決定）。
  - 視頻作品的 Gemini 標題建議併入同一份清單。
- **AI 封面**：比例固定為目前平台（3:4、2.35:1、3:4、6:7），提示詞由標題與正文帶入，生成 4 張。
  - 等待只有一個訊號，圖片 moderate 淡入、不縮放（依 QC-074 規則）。
  - 選一張後按保留：先存進素材庫，再設成這個平台版本的封面，可復原。作品封面不變。
  - 費用無法預估時照常標示。
- **手機模擬**：固定白／黑底，標「排版模擬」。
- **窄視窗**：分欄 400 寬，單欄，「版本｜手機」切換。
- **入口盤點**（EntryAudit 十項）：
  - AI 面板的標題分頁、圖片分頁的封面模式 → 移到預覽。
  - 貼圖的側邊預覽 → 移到同一個分欄。張數／字數膠囊只作提示，點一下打開該平台的預覽。
  - 視頻的抖音、視頻號文案 → 移到預覽。編輯頁只留共用文案。
  - 作品封面、封面幀、摘要與重點時間點留在編輯頁。
