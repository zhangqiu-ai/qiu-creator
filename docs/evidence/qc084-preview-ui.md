# QC-084 前端：編輯頁平台預覽 v2（PT-20261123-001）驗收記錄

日期：2026-11-23 · 會話：qc-frontend · 分支 `qc084-preview`（含後端 3088b0f、78b26ab 的 cherry-pick）

## 範圍

照已核准原型 PT-20261123-001 v2 重做 `PreviewPanel`：

- 每個平台三個畫面：發布編輯、刷到時、正文。可左右切換：點分頁、兩指左右滑，或在分頁上按 ←／→。切換時水平滑動（base），減少動態效果時直接跳。
- 發布編輯在手機上原位編輯：
  - 標題直接打字，字數即時。
  - 圖片用 dnd-kit 拖曳排序，鍵盤也能排。
  - 話題可新增、可刪除。
  - 每欄標「自訂」或「跟隨原稿」，並可「改回跟隨原稿」。
  - AI 標題與選封面（含 AI 封面）以手機內底部面板出現，點選或「設為封面」才套用，可復原。
- 刷到時與正文只能看。在這兩個畫面點標題或封面，會跳回發布編輯並聚焦該欄位。
- 正文由左邊未儲存的草稿即時推導，用 `deriveVariantBody`：
  - 「跟隨」預設開，高亮游標所在段落並捲過去。
  - 超出上限：畫截斷線、淡化之後的文字、平台分頁加橘點，並提供「在原稿標出第 N 字」與「用 AI 縮寫」。縮寫結果是原稿的候選加 diff，保留才寫入。
- 只有手機畫面捲動。縮放：
  - 預設適應高度，另有適應寬度與 50／75／100／150%。
  - ⌘0、⌘＋／⌘－ 只在游標或焦點在舞台時有效；可捏合；放大後按住空白鍵拖曳平移。
  - 記住最後一次的選擇。
- 分欄：
  - 預設 520，可拖曳到 400–720 並記住；←／→ 每次 16，雙擊回 520。
  - 可收合成 44px 平台列。
  - 窄視窗（小於 1360）固定 400，「跟隨」只剩圖示。
- 409：在手機內面板「另一處改了{平台}的{欄位}」，選「保留我的」或「使用對方的」。舊資料另外改過的正文顯示提示，並可改回跟隨原稿。
- 拿掉的部分：正文輸入框、「重新從原稿生成」、版本狀態列、底部欄位列、`VariantSession`。

## 發版前修正（2026-11-23，對應 `docs/evidence/qc084-prerelease.md`）

1. **公眾號摘要與字數含 Markdown 原文（P3）**
   - 修法：在 `packages/platform-preview` 新增 `countedText`／`countedSourceOffset`。
     - 公眾號以文章看得到的文字（各區塊文字，以空行相接）計算；不算圖片語法、`#`、`**`。
     - 另外三個平台不變。
   - 同一根因、一起修好：
     - `checkDerivedLimits` 與 `derivedLength` 改用同一份文字，所以服務端警告、`cut_at`／`source_offset`、平台分頁的橘點、手機上的摘要與字數，算法都一致。
     - 原本服務端的公眾號上限也把 Markdown 語法算進去。
   - 測試：`platform-preview/test/derive.test.ts`（2 個）、`apps/mac/test/preview-stage.test.ts`（1 個）。
2. **editor-tabs.spec 偶發失敗**：根因是測試時序。測試先等游標還原回 11，才呼叫 `setSelectionRange(20)`。沒有加重試、沒有延長逾時、也沒有放寬斷言。單獨連跑 30 次（`--repeat-each=30`，負載 2–4），30 passed，0 failed。
3. **100% 縮放遮擋**
   - 判斷是問題：手機頂端（狀態列、導覽、圖片列）是放大後最想看的區域，卻被畫面分頁蓋住。「復原」在適應高度時也壓在狀態列上。
   - 修法：
     - 手機比舞台高時，頂端停在畫面分頁下方，不再置中（`restingPan`）。空白鍵拖曳仍可平移到底部。
     - 「復原」移到左下角，和縮放列同一排。
   - 仍保留的部分：底部 76px 是縮放列、圓點、「復原」的固定區域。放大時，手機下緣會延伸到這一區底下，拖曳平移就能看到，跟工具列下的捲動內容一樣。
   - e2e 新增兩項斷言：100% 時手機頂端在畫面分頁之下；「復原」不和手機重疊。截圖：`qc084/qc084-6-zoom-100.png`。
