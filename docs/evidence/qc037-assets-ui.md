## 做了什麼（`apps/mac/src/renderer/AssetsPage.tsx`、`asset-session.ts`）

- **範圍**：頂部是「全部／未引用／最近刪除」三段，最近刪除旁顯示數量。類型篩選移到格線上方，右側提示「⌘ 點選多選 · ⌘⌫ 刪除」。
- **素材資訊**（取代原本唯讀的檢視器）：
  - 名稱可直接編輯（`display_name`），清空時回到原檔名；旁邊顯示副檔名 chip。
  - 標籤沿用 `TagEditor`，組字時按 Enter 不會新增。另有替代文字、備註。
  - 600 ms 後自動儲存，失焦時立即儲存，切換素材時先存完再離開；狀態 chip 顯示已儲存／未儲存／儲存中／儲存失敗／有衝突。
  - 「檔案資訊」收在可展開區；底部是「在 Finder 顯示」與刪除。
- **409 衝突**：
  - 重新讀取最新版本，逐欄比對：別處沒改的欄位重套後再存。
  - 同一欄兩邊都改了就不覆蓋，顯示「某欄位已在別處被修改，要保留哪一份」，讓使用者選「用最新的」或「用我的」。在選之前不會寫入。
- **刪除規則**（照已定案的決策）：
  - 未引用的託管素材：直接移到最近刪除，提示附「復原」（⌘Z），6 秒後消失。
  - 被引用的：服務回 409 `asset_in_use` 時，確認框列出引用的作品（可點開），按「移到最近刪除」後帶 `confirm` 再刪；提示「作品顯示為缺圖」並附復原。
  - 外部掛載：確認框有兩個選項，預設「只從素材庫移除」，選「原檔也移到系統垃圾桶」時，按鈕變成紅色的「移到垃圾桶」。`trash_failed` 時錯誤留在確認框裡。
  - 所有確認框的預設焦點都在「取消」，按鈕用具體的動詞。
- **多選**：
  - ⌘／Shift 點選，或點縮圖左上的勾選框；已有選取時，一般點擊也是切換選取。esc 取消選取。
  - 標頭換成批次工具列：「已選 N · 加標籤 · 移到最近刪除 · 取消」。右側改成多選摘要。
  - **批次加標籤**：可一次輸入多個，用逗號或空白分開。
  - **批次移除**：確認框列出託管與外部各幾個（外部只移出素材庫）。若有被引用的，第一次送出會得到 409，確認框改寫「其中 N 個被作品引用」，按鈕變成「仍要移除」。
- **最近刪除**：
  - 每列顯示縮圖、名稱、原位置、刪除時間、剩餘天數（7 天內用警示色），外部素材顯示「已移出」或「原檔在垃圾桶」。
  - 可「恢復」或「永久刪除」；`asset_file_missing` 時在該列提示先在 Finder「放回原處」。
  - 「清空」需要確認。永久刪除或清空後，若 `markdown_referrers` 不是空的，提示哪些作品的正文會出現缺圖。
- **快捷鍵**：⌘⌫ 刪除選取（輸入框內不觸發）、⌘Z 復原剛刪的、esc 取消多選。

## 原型沒畫清楚、我選的做法

- **「未引用」標記**：原型在格子上畫了「未引用」標記，但素材列表的 API 沒有引用數，所以改用「未引用」範圍篩選，格子上不畫標記。
- **搜尋**：原型寫「名稱、標籤、備註」，但 API 的 `q` 只比對顯示名稱與原檔名，所以 placeholder 寫「搜尋名稱」。
- **批次移除標籤**：API 支援，但原型沒有入口，這次只做加標籤；需要時再加。
- **批次移除的引用數**：先不帶 confirm 送出，由服務回答有幾個被引用，再請使用者確認。這樣不必在打開確認框時逐一查引用。
- **外部素材的確認**：外部素材一律先開確認框，即使未被引用，因為原型的確認框就是讓使用者選原檔怎麼處理。
