## 2026-11-24 · MCP：讓其他 Agent 操作整個軟體（QC-087～QC-093）

- 使用者原話：「供其它Agent調用的MCP結構，其它Agent可以調用接口做很多事情，比如新建文章、上傳素材、查看內容、編輯內容，還能根據項目來自動識別哪些內容屬於哪個項目等等。幾乎可以說其它Agent能操作整個軟件內的功能。並且後續新功能的設計也要自動同步新的MCP」。
- 規劃見 [MCP 規劃](mcp-plan.md)。第一期只做本機 stdio（`creatorhub mcp`），只經 `api-client`，不開新的對外埠。
- Agent 改正文預設走提案（候選加 diff，使用者採用才生效）；使用者可對個別權杖打開「允許直接修改正文」，仍帶 `base_revision`、寫入前留快照、標明是哪個 Agent，可一鍵恢復。這是「嚴禁 AI 直接覆蓋原文」唯一的例外，必須由使用者對該權杖明確打開。
- 雲端 AI（改寫、標題、視頻理解）第一版不開放給 Agent。
- 項目歸屬：服務依項目描述與規則給建議和原因，由 Agent 決定；`auto_assign` 只在分數夠高時歸入，可復原。
- 每個 `/api/v1` 路由必須對應 MCP 工具或列入排除清單並寫原因，由覆蓋測試強制。
- 優先順序：排在 QC-033 日常使用驗收之前，P1。

## 2026-11-21 · 補齊貼圖、視頻創作，作品編輯改成多分頁（QC-044–047）

- 使用者原話：「目前作品庫只能創建文章，我需要的是公眾號貼圖和視頻創作也要補齊……視頻創作就需要你自己去發散構思了。還有作品編輯界面目前只支持單個編輯，可以改成並行通過頂部標籤的方式來方便多個之間切換。」附微信公眾號「貼圖」編輯畫面截圖作參考。
- 契約已有作品類型 `article`／`image`／`video`／`mixed`，但「新建」只建立文章，類型篩選也只有文章有內容。
- 新建改為先選類型：文章、貼圖（圖片為主，加標題與描述）、視頻。混合類型暫不另做入口。
- **貼圖**：參考公眾號貼圖。
  - 圖片格可排序、可設封面，數量上限依平台。
  - 標題與描述是短文，不是長篇 Markdown。
  - 可從素材庫挑選、上傳、⌘V 貼上、從 Finder 拖入，沿用 QC-039 的插入流程。
- **視頻**：由原型會話發散構思，總監把關。方向是「圍繞一支視頻組稿」，不做剪輯：
  - 選擇或上傳視頻，可播放，選封面幀或另傳封面。
  - 標題、簡介、話題標籤。
  - 可接 Gemini 視頻理解產生摘要、重點時間點，以及標題、簡介、封面的建議；候選先確認再採用，照「AI 不覆蓋原文」的規則。
  - 抖音與視頻號的平台版本與預覽。
- **多分頁編輯**：
  - 頂部分頁可同時開多個作品，切換時保留各自的捲動位置、游標、模式與未存狀態。
  - 關閉有未存內容的分頁要提示。快捷鍵：⌘W 關閉、⌘⇧[ ] 切換、⌘1–9 跳到指定分頁。
  - 重開 App 時恢復上次開著的分頁。
- 原稿保護不變：仍以 Markdown 或實體檔為權威，寫回帶 revision，衝突回 409，媒體是磁碟檔。貼圖與視頻作品的存放格式由後端設計提出、總監核准。
- 屬於新頁面與新流程，要先做原型（PT），核准後才施工。
- 原型核准：使用者原本要親自核准，之後改口：「我改主意了，你幫我核准即可。」PT-20261121-001 由總監代為核准，`approvedBy` 記總監並引用此條。
- 發版：使用者說「做完直接發版安裝」。QC-045–047 驗收合併後，由 qc-release 直接升級本機安裝，不再另問。可以分批發，也可以全部完成後一次發。

## 2026-11-21 · 介面多語言：简体中文、繁體中文、English（QC-042）

- 使用者原話：「先給應用加上多語言切換：中文簡體、繁體、英語」。
- 語言：繁體中文（現有文案為來源）、简体中文、English。設定 → 外觀加「語言」：跟隨系統（預設）／简体中文／繁體中文／English。即時切換，不需重開；原生選單、對話框、通知一起切換。

- 跟隨系統的對應：macOS 偏好語言 `zh-Hans`／`zh-CN`／`zh-SG` → 简体；`zh-Hant`／`zh-TW`／`zh-HK`／`zh-MO` → 繁體；`en*` → English；其他語言 → English。
- 翻譯範圍：Mac App 所有介面文案、錯誤提示（服務回錯誤碼，由介面依碼對應文案）、日期、數字、相對時間（`Intl`）。
- 不翻譯：使用者內容；四平台模擬預覽中平台自身的介面文字（照平台真實樣子）；AI 提示詞與輸出；`docs/`、日誌、服務端 API 的 message。
- 文案目錄放在不綁 Electron 的共用套件，第二期 iPhone／iPad 直接沿用。
- 不新增頁面，語言選項沿用設定頁的主題卡片樣式，因此不另做原型；由總監以三種語言的截圖驗收。

## 2026-11-18 · Mac 生產可用（QC-004）的安裝、備份與驗收

  - **M1｜本地素材庫 + 統一接入中心**：範圍和原方案相同。
  - **M2｜Mac 完整作品管理 + 平台模擬預覽**：
    - 作品庫、編輯、版本歷史與恢復。
    - 衝突保護：Electron、外部編輯器、Agent API 三方同時修改時，不得靜默覆蓋。
    - 四平台的獨立版本與預覽。
  - **M3｜AI 創作 + Gemini 視頻理解**：在 Mac 上發起和查看。
  - **生產可用驗收**：
    - launchd 安裝與開機自啟、崩潰恢復、SQLite 備份與還原、原稿保護。
    - 日常使用一輪沒有阻斷性問題。
    - 由「項目發版」會話打包安裝。
- **第二期：iPhone／iPad**，在 Mac 生產可用驗收通過後才開工。
  - Tailscale 遠端存取、裝置配對與權杖。
  - Expo 工程（iPhone 與 iPad 雙欄），WebView 嵌入的編輯器。

**為了不讓第二期返工，第一期仍要守住的事**

- Mac App 也只透過 HTTP API 讀寫服務，不直接連資料庫或碰內容檔案的寫入。
- 鑑權權杖、`base_revision`／`If-Match` 與 409、Range、冪等鍵、變更事件（SSE），第一期就照方案實作。
- 共用的 `packages/contracts`、`api-client`、`platform-preview`、`markdown-editor-web` 不得綁死 Electron。
- 第一期不建 `apps/mobile`，不做 Tailscale 設定、裝置配對介面、RN WebView 訊息橋。原型只做 Mac 畫面。
