## QC-070: 文章編輯加 AI 圖片／封面生成與選取浮動工具列

**Priority:** P1 | **Assignee:** qc-prototype（原型，總監代核准）→ qc-backend ＋ qc-frontend | **Tags:** M3, prototype, backend, frontend

使用者 2026-11-22 授權：與 QC-067、QC-068、QC-069 同一版發，全部驗收合併後安裝。決策見 `docs/decisions.md`。
使用者原話（附截圖：選取一段後右側 AI 面板只有「改寫／標題」，選取處沒有任何浮動工具）：「文章編輯右側需要增加AI圖片生成和封面生成功能，New Api 支持生成圖片的。選中段落自動彈出各種功能圖標，AI擴寫、圖片生成等等，並且圖片要自動插入，文字替換和圖片生成和插入的時候都要有過渡動畫和等待動畫！」

**進度（2026-11-22）**：後端已合併（3ea3f53：生圖與封面作業、候選暫存 `cache/ai-images` 24h、保留寫 ai_accepted、URL 下載防 SSRF）；原型 PT-20261122-002 由總監代核准。剩前端。

**範圍**
1. **選取浮動工具列**：選取文字後在選取處上方浮出圖示列：潤色、擴寫、縮寫、語氣、配圖（依選取內容生成圖片）、更多（補充指令）。鍵盤可達、Esc 關閉、不擋輸入法組字、不在原始碼模式遮住文字。
2. **原位候選**：
   - 文字：結果以 diff（刪除線＋新增高亮）就地出現，浮出「保留／捨棄／重試」；保留才寫入並成為 `ai_accepted` 版本，可在歷史還原。
   - 圖片：生成中在插入點顯示同尺寸的骨架佔位（等待動畫）；完成後圖片淡入落位，帶「保留／捨棄／重新生成」；保留後檔案存入作品 `assets/` 並寫入 Markdown 圖片。
3. **右側面板加「圖片」分頁**：提示詞（可由選取文字或全文自動帶入）、風格／比例（1:1、3:4、16:9 等，含小紅書、公眾號封面常用比例）、張數、生成歷史縮圖；「插入到游標處」與「設為封面」。**封面生成**：依標題＋摘要生成，可直接設為作品封面（front matter cover），比例依平台。
4. **動效**：依 DESIGN.md「動效」：浮動工具列 popover 規則；生成中骨架與進度；文字候選交叉淡化；圖片淡入＋版面讓位；保留／捨棄的退場；減少動態效果時只淡入淡出。
5. **後端**：New API `POST {base_url}/images/generations`（金鑰只在 Mac、不進日誌）、模型選擇沿用 QC-054 清單（kind=image）、逾時與大小限制、回傳 base64 或 URL 皆可（URL 下載要防 SSRF）、圖片存成作品 assets 檔案、作業進度事件、可取消、費用：有價格就估算，沒有就標「無法預估」並在首次使用時告知；只在使用者按下時送出。
6. 不直接覆蓋原文；未保留的候選不寫入原稿（可存在暫存，關閉作品時提示）。
- 測試一律用假中轉站；真實生成需使用者自己在安裝版操作。
