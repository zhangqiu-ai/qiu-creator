## QC-095: 原型：Agent 工作中的即時狀態與動效

**Priority:** P1 | **Assignee:** qc-prototype | **Tags:** M3, prototype

使用者 2026-11-25 要求：Agent 經 MCP 操作某件作品時，作品卡片（以及編輯頁、側欄）要有即時的動態效果，表示「有 Agent 正在處理」，並看得出是哪個 Agent（權杖名稱），讓使用者清楚任務狀態、感受到作品正在被認真處理。範圍：作品卡片、列表模式、編輯頁頂部、側欄項目／全部作品的計數旁；狀態至少有「工作中」「剛完成」「出錯／等待你確認（例如提案待審）」與閒置；多個 Agent 同時處理同一件作品；Agent 可選擇回報目前步驟（例如「配圖生成中」）；減少動態效果（reduce motion）時的替代呈現。需先給使用者核准。

**Started:** 2026-11-25
